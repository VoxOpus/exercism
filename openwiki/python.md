The Python track contains numerous exercises to practice Python programming, ranging from basic introductory concepts to more advanced logic and data structure exercises.

## Available Exercises

A selection of the exercises includes:

- **Hello World**: The traditional introductory exercise to print "Hello, World!".
- **Guido's Gorgeous Lasagna**: An introductory exercise teaching basic variables and functions.
- **Ghost Gobble Arcade Game**: Teaches booleans and logic operators.
- **Currency Exchange**: Teaches numbers and basic arithmetic.
- **Meltdown Mitigation**: Teaches conditionals (`if`, `elif`, `else`).
- **Black Jack**: Teaches comparisons and control flow.
- **Little Sister's Vocab** and **Little Sister's Essay**: Teach strings and string methods.
- **Chaitana's Colossal Coaster**: Teaches lists and list methods.
- **Card Games**: Teaches list loops and iteration.
- **Making the Grade**: Teaches loops (`for`, `while`).

## Structure

Each exercise contains:

- `README.md`: Problem description and introduction to language concepts.
- `HELP.md` and `HINTS.md`: Help on running tests, submitting code, and hints for the exercise.
- Source `.py` files.
- Pytest-based `_test.py` files.
