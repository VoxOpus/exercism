The C track contains introductory and algorithmic exercises to practice C programming.

## Available Exercises

1. **Hello World**: The traditional introductory exercise to print "Hello, World!". It verifies the basic build and test environment is working.
2. **Leap**: A logic exercise to determine if a given year is a leap year based on Gregorian calendar rules.
3. **Difference of Squares**: A mathematical exercise to find the difference between the square of the sum and the sum of the squares of the first N natural numbers.

## Structure

Each exercise contains:

- `README.md`: Instructions and problem description.
- `HELP.md`: Help on running tests and submitting code.
- `makefile`: Build script to run the tests.
- Source code files (e.g., `hello_world.c`, `hello_world.h`).
- Test suite files (e.g., `test_hello_world.c` and a `test-framework/` directory).
