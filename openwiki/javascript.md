The JavaScript track contains introductory exercises to practice basic JavaScript programming features and variables.

## Available Exercises

1. **Hello World**: The traditional introductory exercise to print "Hello, World!" and ensure the Node.js/JS setup works.
2. **Lucian's Luscious Lasagna**: An introductory exercise teaching basics like variables, constants, and assignments in JavaScript.

## Structure

Each exercise contains:

- `README.md`: Problem description and introduction to language concepts.
- `HELP.md`: Help on running tests and submitting code.
- `HINTS.md`: (For some exercises) Hints on how to solve the exercise.
- Source `.js` files and test `.spec.js` files.
