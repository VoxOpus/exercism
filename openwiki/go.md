The Go track contains exercises that teach basic language constructs like packages, functions, variables, and booleans in Go.

## Available Exercises

1. **Hello World**: The traditional introductory exercise to print "Hello, World!" and ensure the Go setup works.
2. **Annalyn's Infiltration**: An introductory exercise teaching booleans and logical operators in Go.
3. **Gopher's Gorgeous Lasagna**: An introductory exercise introducing three major language features: Packages, Functions, and Variables.

## Structure

Each exercise contains:

- `README.md`: Problem description and introduction to language concepts.
- `HELP.md`: Help on running tests and submitting code.
- `HINTS.md`: (For some exercises) Hints on how to solve the exercise.
- Source `.go` files and testing `_test.go` files.
