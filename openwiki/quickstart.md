This repository contains solutions for various programming exercises from [Exercism](https://exercism.org).

## Available Tracks

The repository includes exercises solved in the following programming languages:

- [C Exercises](./c.md): Basic and algorithmic exercises.
- [Emacs Lisp Exercises](./emacs-lisp.md): Functional programming exercises.
- [Go Exercises](./go.md): Basic language features and types.
- [JavaScript Exercises](./javascript.md): Variables and dynamic language basics.
- [Python Exercises](./python.md): A wide range of introductory to intermediate language concepts.

## Using the Exercises

Each language track resides in its own top-level directory (e.g., `c/`, `python/`).
Inside each track directory are individual exercise folders (e.g., `c/hello-world/`).

Each exercise includes:

- A `README.md` with the problem description.
- A `HELP.md` containing generic instructions on how to test and submit the exercise.
- Implementation and test files specific to the track's language.

Navigate into the language track of interest, then into the specific exercise folder, and follow the instructions in the `README.md` and `HELP.md` to run the tests and examine the solution.
