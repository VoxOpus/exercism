The Emacs Lisp track contains exercises to practice functional programming in Emacs Lisp.

## Available Exercises

1. **Hello World**: The traditional introductory exercise to return the string "Hello, World!", verifying the basic testing setup.
2. **Accumulate**: Implement an operation that applies a given function to each element of a collection, returning a new collection of the results.
3. **Acronym**: Convert a phrase to its acronym, handling specific punctuation rules.

## Structure

Each exercise generally contains:

- `README.md`: Instructions and problem description.
- `HELP.md`: Help on running tests and submitting code.
- Source and test `.el` files.
